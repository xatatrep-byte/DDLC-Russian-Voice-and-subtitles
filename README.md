# DDLC Russian Voice — v1.0.2

Русская озвучка + поддержка русских субтитров для **оригинальной Doki Doki Literature Club (2017)**.

> Это фанатский проект. Он не является официальным продуктом Team Salvato и не аффилирован с Team Salvato.

## Скачать готовую версию

Для обычной установки используйте архив из раздела **Releases**:

`DDLC-RussianVoice-v1.0.2-Full-Public.zip`

Готовый Release содержит:

- русские субтитры SUN-TEAM Studio v1.0;
- DDLC Russian Voice v1.0.2;
- безопасный установщик;
- диагностику;
- восстановление последнего backup.

Сам GitHub-репозиторий **не хранит бинарные файлы русификатора `scripts.rpa` / `fonts.rpa`**.
Они находятся только в готовом Release ZIP.

## Быстрая установка

1. Установите оригинальную **Doki Doki Literature Club (2017)**.
2. Скачайте `DDLC-RussianVoice-v1.0.2-Full-Public.zip` из **Releases**.
3. Распакуйте архив в отдельную папку.
4. Полностью закройте DDLC.
5. Запустите `install.bat`.
6. Дождитесь `INSTALLATION COMPLETE`.
7. Запустите DDLC через Steam.

## Что делает установщик

`install.bat`:

1. Ищет установленную DDLC, включая дополнительные Steam Library.
2. Проверяет, что это оригинальная DDLC 2017, а не DDLC Plus.
3. Проверяет наличие русского перевода.
4. Если обнаружен точный **SUN-TEAM Studio v1.0**:
   - не перезаписывает его;
   - сразу переходит к установке озвучки.
5. Если обнаружен другой совместимый русский перевод:
   - сохраняет его;
   - ставит только озвучку.
6. Если русского перевода нет:
   - устанавливает SUN-TEAM Studio v1.0 из Release payload;
   - проверяет установленные файлы;
   - затем ставит озвучку.
7. Если обнаружены потенциально конфликтующие Ren'Py-моды:
   - безопасно останавливается до замены `scripts.rpa`.
8. Удаляет дублирующиеся voice-hook файлы.
9. Ставит стабильный runtime **v0.5.2.3 Acting Lite / Natural Dashes**.
10. Проверяет Python / PyTorch / Silero.
11. При необходимости создаёт изолированный Python venv.
12. Для NVIDIA использует CUDA-сборку PyTorch.
13. Скачивает Silero `v5_5_ru`, если модели ещё нет.
14. Запускает генерационный self-test.

## Безопасность повторной установки

Установщик можно запускать повторно.

Если SUN-TEAM Studio v1.0 уже установлен, он определяется и **не перезаписывается**.

Перед заменой файлов создаётся backup:

`<DDLC>\_DDLC_RussianVoice_Backups\YYYYMMDD_HHMMSS`

Backup находится **вне `game`**, поэтому Ren'Py не сможет случайно исполнить резервную `.rpy`-копию.

## Озвучка

Текущая стабильная база:

`v0.5.2.3 Acting Lite / Natural Dashes`

### Персонажи

- **Саёри** — `baya`, medium / fast
- **Нацуки** — `kseniya`, medium / fast
- **Моника** — `baya`, medium / medium
- **Юри** — `xenia`, medium / slow
- **ГГ** — `aidar`, medium / medium

### Acting Lite

Реплики обрабатываются по пунктуации:

- `!`
- `?`
- `.`
- `,`
- `...`
- `—`

Интонация и паузы меняются локально, а не одним параметром на всю строку.

### Natural Dashes

Конструкции вида:

`фраза — продолжение`

по возможности остаются одним spoken/prosody-фрагментом для всех персонажей.

Слова вроде:

`кто-то`, `как-нибудь`, `по-прежнему`

не разрезаются по дефису.

## Управление в игре

- `F8` — включить/выключить озвучку
- `F9` — повторить последнюю реплику
- `F10` — тест озвучки

## Диагностика

Запустите:

`diagnose.bat`

Если создаёте bug report, приложите:

- вывод `diagnose.bat`;
- `game/voice_mod/mod.log`, если существует;
- `game/voice_mod/neural/neural.log`, если существует.

Не загружайте полную копию DDLC.

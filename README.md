# DDLC Russian Voice + Russian Subtitles v1.0.5

Полный установщик для оригинальной **Doki Doki Literature Club (2017)**.

## Главное изменение v1.0.5

Установщик больше НЕ пытается собирать SUN-TEAM из отдельных файлов.

В полный архив релиза `DDLC-RussianVoice-v1.0.5.zip` уже включён исходный архив SUN-TEAM:

`DDLC_1.0_PC.rar`

Отдельно скачивать русификатор SUN-TEAM не требуется.

SHA-256 исходного архива:

`15f4ffe7bb5e91a81e21e2c30448c3070e1511278187347fd2d1b719a5c01837`

При установке `install.bat`:

1. Находит установленную оригинальную DDLC 2017.
2. Проверяет целостность `DDLC_1.0_PC.rar`.
3. Проверяет архив через 7-Zip.
4. Удаляет старые `game`, `renpy`, `lib`, `characters`.
5. Распаковывает **весь DDLC_1.0_PC.rar** прямо в папку DDLC с заменой.
6. Проверяет точные файлы русского SUN-TEAM и Ren'Py 6.99.13.
7. Только после этого устанавливает нашу русскую Silero-озвучку.
8. Настраивает Python / PyTorch / Silero и выполняет self-test.

То есть русская база теперь устанавливается ровно из полного SUN-TEAM архива, а не реконструируется нашим установщиком.

## ⏳ Время установки

**Первая установка обычно занимает около 10–15 минут.** На некоторых компьютерах она может занять больше времени.

Это нормально: установщик при необходимости автоматически устанавливает или настраивает **7-Zip, Python 3.11, PyTorch и Silero**, а также распаковывает полный архив SUN-TEAM и выполняет проверки.

Во время установки **не закрывайте окно `install.bat`**, даже если на каком-то этапе несколько минут кажется, что ничего не происходит. Дождитесь сообщения:

`INSTALLATION COMPLETE`

## Установка

1. Установить оригинальную DDLC 2017 через Steam.
2. Распаковать этот релиз в отдельную папку.
3. Полностью закрыть DDLC.
4. Запустить `install.bat`.
5. Дождаться `INSTALLATION COMPLETE`.
6. Запустить DDLC через Steam.

Если 7-Zip отсутствует, установщик попробует поставить его через `winget`.
Python 3.11 также может быть автоматически установлен через `winget`.

## Важно

v1.0.5 намеренно делает **полную замену игровых/runtime-файлов SUN-TEAM**.
Сторонние моды в `game`, `renpy`, `lib`, `characters` будут удалены.

Сохранения DDLC находятся вне этих папок и установщиком не удаляются.

## Управление

- `F8` — включить/выключить озвучку
- `F9` — повторить последнюю реплику
- `F10` — тест озвучки

## Проверенные исправления

## Главное изменение v1.0.5

Установщик теперь использует полный оригинальный архив русификатора SUN-TEAM, а не собирает перевод из отдельных файлов.

Русские субтитры устанавливаются автоматически, после чего поверх них устанавливается русская Silero-озвучка.

Пользователю достаточно установить оригинальную DDLC 2017 и запустить `install.bat`.

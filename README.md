# DDLC Russian Voice — v1.0.2 Full Safe Installer

Русская локальная озвучка **оригинальной DDLC 2017**.

## Что делает установщик

`install.bat`:

1. Находит установленную DDLC (включая дополнительные Steam Library).
2. Проверяет, что это оригинальная DDLC, а не DDLC Plus.
3. Ищет русский перевод.
4. Если обнаружен точный **SUN-TEAM Studio v1.0** — **не трогает** русификатор.
5. Если обнаружен другой уже работающий русский перевод — **не трогает** его и ставит только озвучку.
6. Если русского перевода нет:
   - в локальном/private bundle ставит SUN-TEAM Studio v1.0;
   - перед заменой делает backup за пределами `game`;
   - если обнаружен другой Ren'Py-мод, безопасно останавливается.
7. Удаляет дублирующиеся voice-hook файлы, чтобы не было рекурсивного вылета.
8. Ставит стабильную озвучку v0.5.2.3 Acting Lite.
9. При необходимости создаёт Python venv, ставит PyTorch и скачивает Silero `v5_5_ru`.
10. Запускает self-test.

## Безопасность повторной установки

Установщик можно запускать повторно.

Если SUN-TEAM уже стоит, он определяется по SHA-256 и **не перезаписывается**.

Если стоит другой русский перевод, он определяется по русскому тексту в `common.rpym`
и `scripts.rpa` и сохраняется.

Перед любой заменой файлов создаётся:

`<DDLC>\_DDLC_RussianVoice_Backups\YYYYMMDD_HHMMSS`

Это находится **вне `game`**, поэтому Ren'Py не будет исполнять резервные `.rpy`.

## Публичный GitHub draft

Этот вариант не содержит SUN-TEAM `scripts.rpa/fonts.rpa`. Если русский перевод уже установлен, `install.bat` сразу поставит озвучку. Если его нет — установщик безопасно остановится и попросит сначала поставить перевод из исходного источника.

## Установка

1. Установите оригинальную **Doki Doki Literature Club**.
2. Распакуйте этот архив.
3. Закройте игру.
4. Запустите `install.bat`.
5. После `INSTALLATION COMPLETE` запустите DDLC через Steam.

## Управление в игре

- `F8` — включить/выключить озвучку
- `F9` — повторить последнюю реплику
- `F10` — тест озвучки

## Диагностика

`diagnose.bat`

## Откат

`restore-latest-backup.bat`

## Русский перевод

Используется русификатор **SUN-TEAM Studio**, версия 1.0.

В переведённом `credits.rpyc` исходного архива присутствует строка:
`Перевод на русский выполнен SUN-TEAM Studio`.

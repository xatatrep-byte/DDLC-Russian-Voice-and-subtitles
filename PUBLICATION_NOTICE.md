# Publication Notice

## DDLC

Этот проект предназначен для установки поверх **оригинальной Doki Doki Literature Club (2017)**.

Репозиторий не содержит полную копию игры.

В исходники репозитория не включаются:

- `DDLC.exe`
- `audio.rpa`
- `images.rpa`
- полный Ren'Py runtime игры
- полный standalone-дистрибутив DDLC

Пользователь должен иметь установленную оригинальную DDLC.

## Release ZIP

Готовый пользовательский Release ZIP может содержать необходимые файлы
русского перевода SUN-TEAM Studio v1.0 вместе с файлами установщика и озвучки.

Сам Git-репозиторий оставляется без бинарных `.rpa` русификатора, чтобы история
исходников оставалась компактной и понятной.

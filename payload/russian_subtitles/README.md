# Russian subtitle payload intentionally omitted

The public repository draft does **not** include the SUN-TEAM `scripts.rpa` / `fonts.rpa`
payload.

The installer can:
- detect an already installed SUN-TEAM Studio v1.0 translation and continue;
- detect another Russian localization and preserve it;
- in a private/local build, use a populated `payload/russian_subtitles/game` directory.

See `PUBLICATION_NOTICE.md`.

# SUN-TEAM Studio Russian Translation

В полном пользовательском Release используется русский перевод:

**SUN-TEAM Studio v1.0**

## Поведение установщика

Если точная версия SUN-TEAM Studio v1.0 уже обнаружена:

- русификатор не перезаписывается;
- установщик сразу переходит к озвучке.

Если обнаружен другой совместимый русский перевод:

- он сохраняется;
- устанавливается только voice runtime.

Если русского перевода нет:

- сначала устанавливается SUN-TEAM Studio v1.0;
- затем устанавливается DDLC Russian Voice.

## Файлы русификации в Full Release

Полный Release использует только необходимые файлы:

- `game/scripts.rpa`
- `game/fonts.rpa`
- `game/tl/None/common.rpym`
- `game/tl/None/common.rpymc`

Полная копия DDLC в Release не включается.

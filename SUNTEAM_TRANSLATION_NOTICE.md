# SUN-TEAM Studio Russian Translation

В этот release включены необходимые файлы русификатора SUN-TEAM Studio v1.0:

- `game/scripts.rpa`
- `game/fonts.rpa`
- `game/tl/None/common.rpym`
- `game/tl/None/common.rpymc`

Если установщик обнаруживает точную SUN-TEAM v1.0 по SHA-256, эти файлы не
перезаписываются.

Если обнаруживается другой совместимый русский перевод, он также сохраняется,
а установщик ставит только озвучку.

Historic Steam guide:
https://steamcommunity.com/sharedfiles/filedetails/?id=1301396549

Перевод: SUN-TEAM Studio.


## Runtime compatibility in v1.0.5

The bundled SUN-TEAM `scripts.rpa` is paired with its matching Ren'Py 6.99.13 runtime. v1.0.5 installs them as one compatibility unit on clean DDLC installations.

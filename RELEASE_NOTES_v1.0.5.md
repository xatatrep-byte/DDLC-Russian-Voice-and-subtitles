# DDLC Russian Voice v1.0.5

Это релиз с полностью переделанной установкой русского SUN-TEAM baseline.

## Что изменено

Главное: установщик **больше не собирает русификатор по частям**.

Внутри релиза находится исходный `DDLC_1.0_PC.rar`. Установщик проверяет его
SHA-256, тестирует через 7-Zip, удаляет старые `game/renpy/lib/characters`,
распаковывает весь SUN-TEAM архив в DDLC с заменой и только после этого
устанавливает русскую Silero-озвучку.

## Исправления озвучки

- исправлена установка на чистом ПК;
- используется `runtime-ready.flag`;
- Windows SAPI fallback отключён;
- возвращены разные Silero-профили персонажей;
- исправлены реплики с английским ником;
- Acting Lite / Natural Dashes сохранены.

## ⏳ Время установки

**Первая установка в среднем занимает около 10–15 минут**, а на некоторых ПК может занять дольше.

Не закрывайте `install.bat` во время работы. Установщик может автоматически устанавливать **7-Zip, Python 3.11, PyTorch и Silero**, распаковывать полный SUN-TEAM и выполнять self-test. Некоторые этапы могут несколько минут не показывать заметного прогресса.

## Установка

1. Установите оригинальную DDLC 2017.
2. Скачайте `DDLC-RussianVoice-v1.0.5-Full-SUNTEAM-Overlay.zip`.
3. Распакуйте архив полностью.
4. Запустите `install.bat`.
5. Дождитесь `INSTALLATION COMPLETE`.
6. Запустите DDLC через Steam.
